# Investigacion proyectos
## ¿Que son los GitHub projects y como ayudan en la gestion de proyectos?
    Los GitHub Projects son herramientas de GitHub que permiten organizar tareas, issues y Pull Requests dentro de un proyecto.
    Ayudan en la gestion de proyectos porque facilitan el seguimiento del trabajo, la organizacion de tareas y la colaboracion entre los integrantes del equipo

## ¿Que diferencia hay entre Projects y un tablero Kanban tradicional?
GitHub Projects esta integrado directamente con los repositorios, issues y Pull Requests de GitHub, mientras que un tablero Kanban tradicional normalmente es una herramienta separada.
Ademas, GutHub Projects permite automatizar tareas relacionadas con el desarrollo del software.

## ¿Como se pueden automatizar las tareas en GitHub Projects?
Las tareas se pueden automatizar configurando reglas automaticas, por ejemplo mover un issue a "Done" cuando se cierre o cambiarlo a "In Progress" cuando alguien comience a trabajar con el.
