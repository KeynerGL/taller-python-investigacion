# Programa Hola Mundo Profesional
    Un programa de ejemplo que demuestra buenas prácticas de programación en Python.

## Descripción
    Este proyecto es un programa "Hola Mundo" mejorado que incluye:

    - Saludo personalizado
    - Uso de variables y constantes
    - Condicionales
    - Ciclos
    - Documentación básica

## Instalación
    1. Clona el repositorio:

    git clone https://github.com/tu-usuario/taller-python-investigacion.git
    cd taller-python-investigacion


## 2. Crea un entorno virtual:
    python -m venv venv

    En Windows:

    venv\Scripts\activate

## 3. Instala dependencias:
    pip install -r requirements.txt

## Uso
    Ejecuta el programa principal:

    python src/main.py

## Pruebas
    Ejecuta los tests:
    
    python tests/test_main.py
